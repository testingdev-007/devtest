# NovaPay Workshop — Student Template

This is the GitHub template repo for the NovaPay Workshop, a one-day coding
session where students debug, extend, and build a simple banking app with
an AI assistant ("Nova," a GitHub Copilot persona).

Students get this repo by clicking **"Use this template"** on GitHub. Every
file here ends up on a student's machine, so it contains only what a student
needs — nothing else.

## What's in this repo

- **`bank-dashboard.html`** — the buggy banking dashboard. Students find and
  fix the planted bugs during the Bug Hunt.
- **`starter-template.html`** — a scaffolded version of the dashboard with
  guided TODOs, for the Build phase and for younger/struggling students.
- **`challenge.js`** — a pre-loaded buggy function used in Level Up Round 1.
- **`.devcontainer/devcontainer.json`** — configures the Codespace to install
  Live Server and GitHub Copilot automatically.
- **`.github/copilot-instructions.md`** — defines "Nova," the Copilot persona
  students interact with throughout the day.

## Facilitator material does not belong here

Answer keys, facilitator scripts, session plans, printable cheat sheets, and
anything else that reveals a bug or its fix must never be added to this repo.
Students receive a full copy of everything in it — a spoiler here is a
spoiler on every student's machine. That material lives in the private
[stemtastic](https://github.com/testingdev-007/stemtastic) repo instead.
